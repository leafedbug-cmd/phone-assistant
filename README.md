# Phone Assistant — PocketOps Project

This repository hosts **PocketOps**, a personal AI phone administrator designed for Android 16 and Samsung One UI on the Galaxy S24 Ultra (SM-S928U).

## Project Location
The Android application source code, build scripts, tests, and documentation are located in the [`PocketOps/`](./PocketOps/) directory.
